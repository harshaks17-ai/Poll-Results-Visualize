## 7. Methodology & limitations

- Shares are calculated as `option votes / valid responses for that question x 100`, so every question's shares sum to 100%.
- Rows with blank, junk or out-of-scope answers were removed before aggregation; the removed count is documented in `outputs/reports/data_quality_report.md`.
- Margin of error uses the normal approximation `1.96 x sqrt(p(1-p)/n)`, which assumes an approximately random sample.
- This dataset is synthetic. It is generated with deliberate demographic tilts to demonstrate the analysis pipeline, not to describe real opinions.
